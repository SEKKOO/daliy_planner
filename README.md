# 每日计划网页

这是一个本地运行的 HTTP 网页工具，用来按天记录客户工作事项，并把内容保存到电脑本地 SQLite 数据库。

## 已支持功能

- 蓝白风格中文页面
- 每天一条记录，每天可填写多条事项
- 列表字段：客户名称、类型、服务方式、工时、工作内容、遗留事项、存在风险
- 类型字段支持下拉选择：方案交流、方案汇报、POC1、POC2、交付、服务、基建
- 服务方式支持下拉选择：客户现场、远程支持
- 页面顶部的“说明内容 / 录入方式”支持点击编辑、保存
- 页面顶部增加“备注”一列，并与顶部区域统一宽度展示
- 每周支持按周一到周日切换查看和录入
- 删除指定日期记录
- 按月查看日期数、事项数、总工时
- 导出指定月份为 Excel 文件
- 支持导出当天工作日志，由本机 `codex` 生成 Word 日志文档
- 最近记录快速回填
- 已配置每分钟自动巡检 `app.py`

## 运行方式

```bash
cd /Users/vm0/daily_planner_web
python3 app.py
```

然后在浏览器打开：

`http://127.0.0.1:8000`

如果需要局域网访问，请使用当前电脑的局域网 IP，例如：

`http://192.168.64.3:8000`

## 本地数据位置

数据库文件会自动创建在：

`/Users/vm0/daily_planner_web/data/planner.db`

## 使用说明

- 先选择日期，再点击“新增一行”补充当天的多个事项
- 每条事项需要填写客户名称和工作内容，工时支持 `0.5` 递增
- 工作内容、遗留事项、存在风险支持多行输入和自动换行
- 可以点击每周的周一到周日按钮，快速切换并录入当天或后面几天的安排
- 每周工作安排区域支持编辑后自动保存，无需再手动点击保存按钮
- 页面顶部的“说明内容、录入方式、备注”点击编辑后可改为文本框修改，保存后恢复为展示信息
- 点击“导出当日日志”后，会生成包含“今日工作 / 明日计划 / 风险和需要协助 / 思考和其他”的 `.docx` 日志文档，并在内容中带出服务类型归属
- 点击“保存当天列表”后，会覆盖更新该日期的整天记录
- 点击“删除当天记录”可以删除当前日期对应的全部事项
- 右侧选择月份后，可以查看当月全部记录和总工时
- 点击“导出 Excel”会下载该月份的 `.xlsx` 文件
